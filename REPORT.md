## 3. Deep Learning Background
**Artificial Intelligence (AI)** refers to the development of computer systems capable of performing tasks that normally require human intelligence (e.g., image recognition, decision making, natural language processing). 

**Machine Learning** is a subset of AI where computers learn patterns from data. Instead of manually programming rules (such as *IF image has vertical line AND curved portion THEN its 9*), a machine learning algorithm learns patterns automatically from examples.

**Deep Learning** is a subset of Machine Learning that uses artificial neural networks with multiple layers. It is highly useful when a large amount of data is available.

### 3.1 Artificial Neural Network (ANN)
An Artificial Neural Network is a computational model inspired by the general idea of interconnected neurons. A neural network consists of:
1. Input Layer
2. Hidden Layer(s)
3. Output Layer

Each neuron receives inputs, applies weights and bias, and passes the result through an activation function[cite: 8]. The basic mathematical operation performed by a neuron is given as:
`z = Σ (w_i * x_i) + b`
Where:
* `x_i` → inputs
* `w_i` → corresponding weights
* `b` → bias
* `z` → weighted sum

The weighted sum is then passed to an activation function: `a = f(z)`.

### 3.2 Activation Functions
Activation functions are an important component of neural networks because they introduce non-linearity. Without them, multiple layers of linear operations would effectively behave like a single linear transformation Two activation functions were used in this project:
1. **ReLU (Rectified Linear Unit):** Defined as `ReLU(x) = max(0, x)`. If `x > 0`, it outputs `x`. If `x < 0`, it outputs `0`.
2. **Softmax:** The output layer uses the softmax activation function. It converts the outputs into probabilities. For MNIST, there are 10 possible classes, so it generates probabilities for digits 0 to 9.

### 3.3 Loss Function & Optimizer
* **Loss Function:** The model uses `sparse_categorical_crossentropy` as labels are represented as integer class values (0, 1, 2, 3...9). The purpose of the loss function is to measure the difference between the actual class and the prediction generated by the model.
* **Optimizer:** The model uses the `Adam` optimizer. Adam is an optimization algorithm used to update the weights of a neural network during training.
* **Process:** Prediction → Calculate Loss → Calculate Gradients → Update Weights. This process is done recursively throughout repetitions (epochs).

## 5. Methodology & Implementation
The project was implemented using Google Colab and followed a systematic pipeline:
1. **Dataset Loading:** The MNIST dataset was loaded successfully (60k train, 10k test).
2. **Data Exploration:** Dataset dimensions, value ranges, class distribution, and sample images were examined.
3. **Data Preprocessing:** Grayscale pixel values were normalized from 0-255 to a 0-1 scale by dividing each value by 255.0. The 28x28 images were converted to 784-dimensional vectors.
4. **Model Development:** A feedforward neural network was designed with the architecture: `Flatten` → `128 Dense neurons` → `32 Dense neurons`[cite: 8]. ReLU was used in the hidden layers and Softmax in the output layer.
5. **Model Compilation:** Compiled using the Adam optimizer and sparse categorical crossentropy. It was trained for 25 epochs with a batch size of 32 and a 20% validation split.
6. **Evaluation & Prediction:** The trained model was evaluated on unseen test data.
7. **Experimentation:** The hidden layers were modified from 128 and 32 neurons to 256 and 64 neurons while keeping other parameters unchanged to observe performance differences.

## 6. Conclusion
The project successfully implemented a handwritten MNIST digit classification system using a neural network built with TensorFlow/Keras. The dataset was explored, visualized, and normalized before being supplied to the model. 

A baseline neural network consisting of 128 and 32 neuron hidden layers with ReLU activation and a 10-neuron Softmax output layer was trained for 25 epochs using the Adam optimizer. The model was evaluated and achieved approximately 96.27% test accuracy on the final Colab execution. 

The model was also tested on 5 individual images by comparing their actual and predicted labels.. Finally, the hidden-layer sizes were increased to 256 and 64 neurons as an experiment, which resulted in a slight increase in accuracy and a decrease in loss.
